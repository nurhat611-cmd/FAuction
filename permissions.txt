=====================================================================
 FAuction — все разрешения (permissions) для LuckPerms
 Сгенерировано из plugin.yml (шаги 1-5). Узлы чувствительны к регистру
 там, где он указан: FAuction_dubleSlot_* и FAuction_expireDay_* —
 именно так, с большой FA и "duble" без "o".
=====================================================================

БЫСТРЫЙ СТАРТ (консоль или игрок с правами LuckPerms):
  Игрокам:        lp group default permission set fauction.user true
  Администрации: lp group admin   permission set fauction.admin true
  Пример личной выдачи:
                  lp user Steve permission set fauction.nocommission.10 true
                  lp user Steve permission set FAuction_dubleSlot_3 true
  Проверить, что получилось у игрока: /ah admin slots <ник>

---------------------------------------------------------------------
 1. ИГРОКИ (по умолчанию true — выдавать не нужно, можно отбирать)
---------------------------------------------------------------------
fauction.user                [true (у всех)]  Родительский узел игрока: включает list, sell, expire, search, sounds, lookup
fauction.list                [true (у всех)]  Открывать аукцион (/ah и /ah list)
fauction.sell                [true (у всех)]  Выставлять предметы (/ah sell <цена> [количество])
fauction.expire              [true (у всех)]  Забирать просроченные предметы (/ah expire)
fauction.search              [true (у всех)]  Поиск по материалу (/ah search <материал>), регистр не важен
fauction.sounds              [true (у всех)]  Включать/выключать свои звуки аукциона (/ah sounds on|off)
fauction.lookup              [true (у всех)]  Смотреть лоты игрока (/ah lookup <ник>)

 3. АДМИНИСТРАЦИЯ И МОДЕРАЦИЯ (по умолчанию op)
---------------------------------------------------------------------
fauction.admin                         [op]  Родительский узел администрации: все fauction.admin.* и fauction.tabcomplete
fauction.tabcomplete                   [op]  Видеть слова list и expire в таб-подсказках /ah (запускать их могут все)
fauction.mod.cancel                    [op]  Модератор: шифт+ПКМ по чужому лоту снимает его в просроченные владельца
fauction.bypass.spam                   [op]  Игнорировать антиспам-ограничения аукциона
fauction.admin.reload                  [op]  /ah admin reload — перезагрузка конфигурации
fauction.admin.slots                   [op]  /ah admin slots <игрок> — слоты и сроки хранения игрока
fauction.admin.clear.players           [op]  /ah clear data players (= /ah admin purge players) — вайп: лоты, просроченные, история и счётчики бесплатных лотов
fauction.admin.purge.all               [op]  /ah admin purge all — очистить всё (счётчики бесплатных лотов НЕ сбрасывает)
fauction.admin.purge.auction           [op]  /ah admin purge auction — очистить активные лоты
fauction.admin.purge.expire            [op]  /ah admin purge expire — очистить просроченные
fauction.admin.purge.hictoric          [op]  /ah admin purge historic — очистить историю (опечатка hictoric — историческая, так в плагине)
fauction.admin.migrate                 [op]  /ah admin migrate <версия> — миграция данных старых версий
fauction.admin.transfertBddToPaper     [op]  /ah admin transfertToPaper / transfertToBukkit — конвертация БД

=====================================================================
 Примечания
 - Переименование команд в config.yml (секция commands) разрешения НЕ
   двигает: sell под любым именем остаётся fauction.sell.
 - /ah expire и /ah list обычному игроку в подсказках не предлагаются
   (их видят держатели fauction.tabcomplete), но запускаются как раньше.
 - Родительские узлы: fauction.user и fauction.admin — удобнее всего
   вешать на группы, отдельные узлы — точечно игрокам.
